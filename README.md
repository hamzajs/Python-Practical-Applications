# 🚀 Python Practical Applications

A collection of 13 practical Python projects focusing on automation, file processing (PDF, Word, CSV), and API integrations using Pythonic and clean code principles.

## 🛠️ Technologies & Skills Demonstrated

- **Core Python:** String manipulation, Lists, Dictionaries, and Regular Expressions (RegEx).
- **File Handling:** Reading, writing, and manipulating CSV, Excel, PDF, and Word documents securely using Context Managers (`with open`).
- **Web & APIs:** Data extraction via Web Scraping and integration with RESTful APIs (OpenWeatherMap).
- **Databases:** Interacting with databases for task management.
- **Defensive Programming:** Robust error handling (`try...except`) and input validation.

## ⚙️ Prerequisites & Setup

To run these projects locally, ensure you have Python 3 installed. Clone the repository and install the required dependencies:

```bash
git clone [https://github.com/YOUR_USERNAME/Python-Practical-Applications.git](https://github.com/YOUR_USERNAME/Python-Practical-Applications.git)
cd Python-Practical-Applications
pip install -r requirements.txt
```
